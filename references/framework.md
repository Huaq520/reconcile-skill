# 六阶段分析框架

> 这套框架的用途是：把"我觉得他可能不爱我了"这种模糊的痛苦，
> 拆成可以看、可以验证、可以行动的东西。
> 顺序不能乱：**先安全，再事实，再情绪，最后才是策略。**

---

## 阶段 0 · 安全筛查（<30 秒）

逐条过，任一命中 → 立刻停止关系分析，转 `safety.md`：

- [ ] 出现殴打、掐、推搡、拘禁、摔东西、性胁迫
- [ ] 出现"你敢……我就……"、自伤/自杀威胁、拿隐私或裸照要挟
- [ ] 跟踪、堵门、查手机、定位、频繁换号骚扰
- [ ] 用户或对方未满 18 岁且涉及性/亲密关系
- [ ] 对方已明确说"别再联系我"，用户仍想"想办法让 TA 回头"
- [ ] 用户出现自伤念头、持续失眠、无法工作

---

## 阶段 1 · 事实层（只描述，不评价）

### 1.1 时间线
标出 3–5 个节点：关系升温、第一次大冲突、转折事件、断联/分手、最后一次有效沟通。
写"什么时候发生了什么"，不写"他怎么能这样"。

### 1.2 量化信号（有 `stats.py` 输出就直接用，没有就目测）

| 信号 | 可能含义 | 注意 |
|---|---|---|
| 回复长度从长变短，最后只剩"嗯/哦/好" | 撤退、疲惫、或已决定结束 | 也可能只是忙，要看持续多久 |
| 回复延迟从分钟变小时/隔天 | 优先级下降 | 单次不算，趋势才算 |
| 主动发起比例骤降 | 投入减少 | 谁先找谁，是关系温度计 |
| 深夜消息变多、长段落 | 情绪浓度高，可能在反复 | 深夜说的话第二天常后悔 |
| 撤回、反复编辑、发完又删 | 犹豫、试探、怕说错 | 是"还在乎"的信号，但不等于"想复合" |
| 只谈事务（钱、东西、孩子、工作） | 情感通道关闭 | 事务性联系 ≠ 关系修复 |
| 朋友圈/状态可见性变化 | 边界调整 | 不要过度解读，可能是随手设置 |

### 1.3 关键原话
挑 3–5 句信息量最大的，**脱敏后**原样引用（去掉姓名、电话、地址、单位）。
引用要成对：一句用户说的 + 一句对方回的，让模式自己浮出来。

## 阶段 2 · 情绪层（先接住人，别急着分析）

用户此刻通常混着 4–5 种情绪，先命名，再排序：

- 被抛弃感（"我是不是不值得"）
- 愤怒（"凭什么是我改"）
- 自责（"如果那天我没说那句话"）
- 不甘（"我付出这么多"）
- 恐惧（"再也遇不到这样的人"）

写法：
1. 一句复述事实："你们从每天聊到三天没说话，这个落差很伤人。"
2. 一句命名情绪："你现在可能不只是难过，还有一种被否定的感觉。"
3. 一句许可："想哭就哭，不用急着想通。"

**不要**在这层做归因、给建议、评判对方。情绪没被接住时，任何建议都会被当成指责。

## 阶段 3 · 双视角（本 skill 的核心价值）

### 3.1 对方的 3 个假设

每个假设必须四件套，缺一不可：

```
假设 A：TA 还在乎，但害怕重蹈覆辙
  支持证据：分手后仍会回你消息；没有拉黑；共同朋友说 TA 问过你
  反证：回复越来越短；从不主动发起
  置信度：中
  验证方式：问「如果我说我想试试，但这次换种方式，你会愿意听我说完吗」
```

三个假设要**覆盖不同方向**，不要三个都是"TA 还爱你"：
- 一个偏正面（还在乎）
- 一个偏中性（累了/忙/在观望）
- 一个偏负面（已经放下/有新生活）

### 3.2 用户的 1 个盲点

用邀请句式，不说教：
> "有个部分你要不要听听看？你一直在解释'我不是那个意思'，
>  但 TA 可能更想听到的是'我知道那句话让你难受了'。"

### 3.3 反读心规则

- 禁止："TA 就是不爱你了" / "TA 肯定还想着你"
- 必须："从这几条看，更接近……，但这只是推测"
- 每个假设都要给"怎么验证"——把猜测变成一次可以问出口的话

## 阶段 4 · 关系诊断

### 4.1 矛盾类型（选 1 个主类型 + 1 个次类型）

| 类型 | 典型表现 | 修复关键 |
|---|---|---|
| 需求错位 | "我要陪伴，你要空间" | 谈具体可执行的需求，不谈态度 |
| 沟通方式 | 一吵就冷战/翻旧账/人身攻击 | 换句式：事实 + 感受 + 请求 |
| 信任崩塌 | 撒谎、暧昧、隐瞒 | 透明度 + 时间 + 允许对方慢慢信 |
| 外部压力 | 异地、父母、工作、钱 | 先解决结构问题，别把压力算成不爱 |
| 价值观分歧 | 婚育、定居、金钱观 | 诚实面对"可能真的不合适" |
| 单方面消耗 | 一方永远在哄、在追、在改 | 先停损，再谈修复 |

### 4.2 可修复性三问

1. **还有回应吗？** 完全拉黑、换号、明确拒绝 → 低
2. **还有意愿吗？** 愿意对话、愿意见面、愿意听解释 → 中高
3. **是否在有毒循环里？** 和好→冲突→冷战→和好，已循环 3 次以上 → 先破循环再谈复合

给一个 1–5 的判断，并写理由。**不要只给分数**，分数会变成用户的执念。

## 阶段 5 · 行动方案

### 今天（0–24 小时）
- 不连发、不夺命连环 call、不去对方楼下等
- 写一封**不发出**的信，把想说的全写完（情绪出口）
- 睡觉、吃饭、找一个能说话的人
- 如果必须回消息：只回事实，不加情绪（"东西我放门口了"）

### 一周
- 一次低压接触，原则：**短、具体、给对方退路**
- 不谈"我们"，只谈一件具体的事
- 发出后不追问；48 小时没回应就停手

### 一个月
- 观察指标：回应的**质量**（是否愿意多说一句），不是速度
- 止损线：明确拒绝 2 次 / 持续不回应 / 对方已有新关系 → 转"体面收场"
- 自我修复：把"我值不值得"换成"我需要什么"

### 不要做的事（往往比要做的更重要）
- 不要用自伤、醉酒、生病去换关注
- 不要托朋友传话、不要发朋友圈内涵
- 不要查对方社交账号、不要联系对方的新伴侣
- 不要承诺"我什么都改"——空头承诺比不改更伤人

---

## 阶段 6 · 复盘与收场

如果对方不回头，最后一步不是"再试一次"，而是：

1. **承认失去**："这段关系结束了，不是因为我不好。"
2. **提取经验**：我在关系里真正需要什么？我下次会怎么说？
3. **体面告别**：一条不索要回应的消息，然后停。
4. **重建**：睡眠、朋友、运动、工作，先恢复功能，再谈意义。

> "重归于好"有两种：和对方，和自己。
> 第二种，你随时可以开始。
