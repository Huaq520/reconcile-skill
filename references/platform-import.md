# 导入聊天记录：各平台步骤

> 原则：**由用户自己导出，只在本地处理，导出完可以随时删。**
> 不要把账号密码、验证码交给任何第三方工具。

---

## 一、QQ（最简单）

### 方式 A：电脑端导出（推荐）
1. 电脑 QQ → 打开与对方的聊天窗口
2. 右上角「…」/ 消息管理器 → 选中该会话
3. 右键「导出消息记录」→ 选 **txt** 格式
4. 把 txt 交给 skill：
   `python3 scripts/normalize.py 记录.txt -o chat.jsonl --me 你的昵称`

> 导出的 txt 一般长这样：
> `2024-06-01 12:00:01 昵称` 换行 内容，消息之间空行。
> `normalize.py` 能自动识别；识别不准时加 `--me` 指定你的昵称。

### 方式 B：手机端迁移/备份
手机 QQ → 设置 → 通用 → 聊天记录迁移与备份 → 迁移到电脑。
得到的是 QQ 自己的备份格式，需要先用电脑端打开再导出 txt。

### 方式 C：直接粘贴 / 截图
手动复制时，整理成一行一条最省事：
```
我: 你最近是不是很忙
对方: 嗯
```
截图：能看清时间和昵称即可，条数多就分几张。

## 二、微信

微信**没有**官方导出接口。可选路径，按安全性排序：

### 1. 手动复制（最安全）
长按消息 → 多选 → 合并转发到「文件传输助手」→ 电脑端复制成文本。
适合几十条的关键对话。

### 2. 电脑端备份 + 第三方导出工具（谨慎）
常见思路：先用微信自带「备份与恢复」把记录备份到电脑，
再用开源导出工具（如 WeChatMsg / 留痕 类）把备份解析成 CSV / HTML / TXT。

**必须提醒用户：**
- 这类工具要读取本地数据库，属于高风险操作，**先备份、再操作**
- 只从官方仓库/可信来源下载，不要在网盘随便下 exe
- 微信版本更新后工具常失效，失败就退回手动复制
- 不要使用要求登录、上传云端、收费解密的工具

### 3. 导出后的格式
`normalize.py` 支持常见 CSV（含 `StrContent`、`StrTime`、`IsSender` 等列）：

```bash
python3 scripts/normalize.py wechat.csv --format wechat-csv -o chat.jsonl
```

也支持 HTML 导出先另存为 txt 再手工整理，或直接粘进对话。

---

## 三、统一格式（脚本之间约定）

每行一个 JSON 对象：

```json
{"time": "2024-06-01 12:00:01", "sender": "me", "text": "你最近是不是很忙", "kind": "text"}
{"time": "2024-06-01 12:03:20", "sender": "them", "text": "嗯", "kind": "text"}
```

- `sender`：`me` / `them` / 昵称（三方群聊时保留昵称）
- `kind`：`text` / `image` / `voice` / `emoji` / `system`
- 时间统一成 `YYYY-MM-DD HH:MM:SS`（解析不了就留原样，`stats.py` 会跳过）

## 四、隐私清单（发给用户看）

- [ ] 导出文件只放本地，分析完删除
- [ ] 记录里出现的第三方姓名、电话、地址、单位，分析时会被隐去
- [ ] 不把记录粘贴到公开网站、不发给第三方"情感咨询"
- [ ] 裸照、身份证、银行卡等内容，先删除或打码再给
- [ ] 截图前检查顶部状态栏（定位、未读消息、其他 App 通知）
